# State (local learner data)

Personal coaching state lives here and is **gitignored** (except this README and the example template).

| File | Tracked? | Purpose |
|------|----------|---------|
| [`progress.example.md`](progress.example.md) | yes | Starter shape |
| `progress.md` | **no** | Your weak domains, scores, avoid-repeats — updated by `/review` |

On first use, copy the example or let the agent create `progress.md` on the first `/review`:

```bash
cp state/progress.example.md state/progress.md
```
