# State (local learner data)

Your coaching state lives here and is **gitignored**, except this README and the example template.

| File | Tracked? | Purpose |
|---|---|---|
| [`progress.example.md`](progress.example.md) | yes | Starter shape |
| `progress.md` | **no** | Your weak CKS domains, scores and avoid-repeats; updated by `/grade` |

`/grade` creates `progress.md` on first use. `/create-tasks` and `/exam-session` read it to target your weak domains.
